# 宵の一献について

## こんな夜なら、何を食べよう。何を飲もう。

「今日は何飲もうかな」と思ったときに、日本酒の銘柄やスペックを見ても、正直よく分からないことってあると思います。

自分も日本酒は好きだけど、毎回「精米歩合がどう」とか「日本酒度がどう」とか考えて飲んでいるわけではありません。

それより先に、

今日は魚が食べたいな、とか。
寒いから温かいものがいいな、とか。
仕事終わったし、ゆっくり飲みたいな、とか。

だいたいそんなところから晩ごはんを考えています。

だったら日本酒も、そこから選べた方が自然なんじゃないかと思って作り始めたのが「宵の一献」です。

夜の気分を選んで、食べたいものを選んで、料理を選ぶ。

その先に「じゃあ、この酒はどうでしょう」と出てくる。

日本酒に詳しい人だけじゃなくて、普段あまり飲まない人でも使える場所にしたいと思っています。

もちろん銘柄や酒米、精米歩合みたいな情報も大事なので、それはちゃんと残しています。

でも最初から全部覚えなくてもいい。

「これ、おいしそうだな」くらいから一本見つけてもらえたら、それでいいと思っています。


## 酒を飲む側から、米をつくる側へ。

このサイトを作っている自分も、これから生活がかなり変わります。

東京で会社員として働く生活をやめて、地元の佐賀に戻って、農業をやることにしました。

収入も今までより減るし、生活の仕方もたぶん結構変わります。

農業についても、まだ分からないことばかりです。

それでも、これから先どういうふうに生きていきたいかを考えたときに、食べものを作る仕事に自分でもちゃんと関わってみたいと思いました。

中でも、米はずっと気になっていました。

日本酒も米からできているし、毎日食べているごはんも米です。

当たり前すぎて、今まではそこまで深く考えずに食べたり飲んだりしてきました。

でもこれから自分でも田んぼに立って、土に触って、米を作る側のことを知っていくことになります。

実際にやってみたら、今まで見えていなかったものがたぶんたくさんあると思います。

天気ひとつでどう変わるのか。
どれくらい手がかかるのか。
収穫までどんな仕事があるのか。

まだ始めてもいないので、偉そうなことは言えません。

だから今は、「農家だから分かります」みたいなことを書くつもりもありません。

分からないから、これから知っていきたい。

そこで自分が覚えたことや、実際に感じたことがあれば、少しずつこのサイトにも持って帰ってこられたらと思っています。


## 日本酒だけのサイトにはしたくない

宵の一献を作り始めたときは、まず日本酒と料理を合わせるサイトとして考えていました。

でも調べていると、それだけでは終わらないんですよね。

酒を見れば、その土地のことが出てくる。

料理を見れば、そこで採れるものが出てくる。

米があって、水があって、酒蔵があって。

料理を盛る器も、その土地で作られていたりします。

その一つ一つを全部詳しく紹介できるほど、自分もまだ知りません。

でも、せっかくなら少しずつ知っていきたいと思っています。

「この酒おいしそう」で終わるだけじゃなくて、

どこで作られているんだろうとか、
この辺では何を食べるんだろうとか、
こういう器で飲んだらいいなとか。

そんなふうに、興味が横に広がっていく場所にできたら面白いなと思っています。

佐賀に戻って農業を始めれば、自分自身も今までより土地や食べものに近いところで暮らすことになります。

たぶん宵の一献も、それに合わせて少しずつ変わっていくと思います。


## 料理について

このサイトでは、日本酒だけじゃなくて家庭で食べる料理もかなり大事にしています。

ものすごく特別な料理ばかりを合わせたいわけではありません。

焼き魚だったり、煮物だったり、冷奴だったり。

普通の晩ごはんに日本酒が一本ある。

自分はそういう飲み方が好きです。

なので、「高級な料理と高級な酒を合わせるサイト」というより、普段の食卓で使ってもらえる方がうれしいです。

郷土料理や、その土地ならではの食べものも少しずつ増やしていきます。

名前だけ見ても何の料理か分からないものもあるので、そういうものはなるべく簡単に説明を付けるつもりです。

作ってみたいと思った料理には、ちゃんとしたレシピがある外部サイトへのリンクも付けていきます。

宵の一献自体をレシピサイトにするつもりはないので、そこは詳しい人たちに任せます。


## おすすめについて

宵の一献では、できるだけ酒蔵の公式情報などを確認して、日本酒の情報をまとめています。

料理との組み合わせも、酒蔵などが実際におすすめしているものと、このサイトで味の特徴から考えて提案しているものがあります。

そこはなるべく分けて分かるようにします。

もちろん、自分たちで考えた組み合わせが絶対に正解ということでもありません。

味の好みは人それぞれなので、「こんなのもありそうだな」くらいで使ってもらえれば十分です。

そこから自分の好きな組み合わせを見つけてもらえたら、一番いいと思っています。


## 購入リンクについて

サイトには楽天やAmazonなどの商品へのリンクがあります。

そこから購入してもらうと、サイトの運営に収益が入る場合があります。

ただ、

「リンクが取れる酒だからおすすめする」

とか、

「こっちの方が売れそうだから上に出す」

ということはしません。

酒をおすすめする仕組みと、購入リンクは分けています。

買いたい人が、そのまま買えると便利だから置いている。

基本的にはそれくらいのものだと思ってください。

この辺は、なるべく分かりにくいことをしないように運営していくつもりです。


## まだ作っている途中です

宵の一献は、完成したサイトではありません。

今でも少しずつ直しています。

料理の名前が重複していたり、商品画像が見つからなかったり、調べても公式情報が十分に出てこない酒もあります。

そういうところを一つずつ調べて、直している途中です。

これから農業を始めたら、そっちで知ることもたくさんあると思います。

酒のことも、米のことも、料理のことも、土地のことも、自分自身まだ知らないことばかりです。

なので、最初から全部知っている人としてこのサイトを作るつもりはありません。

自分も知りながら、サイトも一緒に良くしていければと思っています。


こんな夜なら、何を食べよう。

何を飲もう。

そんなときに、たまに思い出して開いてもらえるサイトになったらうれしいです。
