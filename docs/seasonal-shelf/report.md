## 棚下げは自動化しない

517は480〜520の目安内。商品数を500に合わせるための削除・水増しはしなかった。今回の救済不可/欠損を理由に既存114商品を一括INACTIVEにしない。次の追加商品が品質ゲートを通過した時点で、next-review-queueの優先商品と入れ替えを審査する。蔵元唯一の登録や地域・酒質の固有性は個別に再検討し、買えない一店舗だけで終売を認定しない。
