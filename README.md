作業元は2026-11-16の最新ローカル隔離版。484商品・正式画像399・アフィリエイト直リンク387の承認台帳と統合済みのCommerce状態を保持する。対象と期限は \`docs/release-readiness/\` を参照。

## 公開Gitブランチでの取り扱い

楽天が発行したアカウント付きURLとHTML、API認証値、\`.env\`、ローカルNetlify状態はGitに入れない。承認・SKU・容量・媒体・期限・ハッシュはコミットする。楽天発行原本はローカルの私有バンドルに分離した。承認の期限は変更していない。

このGitブランチは未登録の別ホストで正式素材を公開しないため、Netlifyで既定のアフィリエイトを無効にしている。公開リポジトリだけでビルドできるが、画像・直リンクの本番候補数をこの無効化プレビューで確認したとは扱わない。Netlifyのビルドは \`noindex\` を維持し、新ブランチのVercel自動デプロイは行わない。

原本付き検証は \`scripts/release-materials.mjs\` でハッシュを検証して新規の隔離作業領域を作り、ローカルでビルドする。バンドルまたはその出力をGitへ追加しない。Netlify正式配信・インデックス解除には、登録媒体での配信形態、GA4管理画面での実受信、実機QAを確定すること。Netlify準備の詳細は \`docs/release-readiness/cutover-runbook.md\`。
